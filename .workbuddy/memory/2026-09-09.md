# 2026-09-09

## 上云部署评估（用户提问，未实际部署）

用户问「这个后端服务部署到服务器上需要什么配置、多少钱一个月」。只做了评估，没改代码、没部署。

### 该服务的资源画像（从代码实测得出）
- **CPU 是唯一硬瓶颈**。ffmpeg libx264：
  - `original` (-c copy) —— 纯 I/O，秒级
  - `fast` (veryfast crf23) —— 1080p 约 2–4x 实时
  - `precise` (medium crf18) —— 1080p 约 0.5–1x 实时，最慢
- **内存很轻**：Node ~150MB + ffmpeg 1080p ~300–600MB（4K 约 1.5–2GB）。2G 能跑，4G 舒服。
- **磁盘是临时性的**：`MAX_UPLOAD_GB` 默认 10（server.js:33），输出再占一份 → 单任务峰值 20GB+。
  已有 60 分钟 TTL + 15 分钟定时兜底清理。
- **带宽/流量是隐性大头**：浏览器预览播放器会拉 `/uploads/<file>`，
  所以「预览一遍 = 出流量 1 个源文件大小」，很多人会忽略这笔。

### 关键结论（选型要点）
- **腾讯云轻量只统计出向流量，入向（用户上传）不计费** → 上传 GB 级视频不花钱，只有下载结果算。
- **腾讯云超流量包后按 0.8 元/GB 后付费**（不是限速），会欠费停机，需开流量预警。
- **阿里云轻量 = 200M 峰值 + 不限流量**，对这种视频上传/下载型应用明显更合适。
- 坑：中国大陆域名要 ICP 备案；轻量首年是活动价，**续费恢复原价**（4核8G 可能从 ~37 元/月 跳到 ~200 元/月）。

### 给用户的建议（三档）
| 场景 | 配置 | 大致月成本 |
|---|---|---|
| 自用偶尔用，1080p 短视频 | 2核4G / 60–80G SSD / 200M / 不限流量 | 17–75 元 |
| **推荐**：主营 1080p，偶尔精确模式 | **4核8G / 100G SSD / 200M / 不限流量** | **37–220 元（首年低、续费高）** |
| 常处理 4K / 多人共用 | 8核16G / 200G SSD | 150–300 元 |

### 上云前必改的代码项（若真要部署）
1. `MAX_UPLOAD_GB` 从 10 降到 1–2，否则 70G 盘两并发就撑爆。
2. 加鉴权（目前完全裸奔，任何人都能当免费转码机用）。
3. nginx `client_max_body_size 0` + `proxy_read_timeout` 放宽。
4. PM2 守护 + 开机自启。
5. 装 ffmpeg/ffprobe（镜像默认没有）。

### 诚实建议（已告知用户）
这就是个「文件不出本机」的本地工具，自用场景下上云反而更慢（要先传 GB 级原片）
且多花钱。上云真正有价值的情况：想在别的设备/外面用、手机上传、给同事共用。

## 换片键改为右上角固定悬浮（frontend-design 技能）

沿用既有「工业剪辑台 / 场记板」语言，不另起方向。

- **结构**：`#newVideoBar` 从 `<main>` 里移出，成为 `<body>` 直接子元素（固定定位更干净）。
  类名 `new-video-bar` → `reel-bar`；按钮 `btn btn-ghost` → `reel-tab`。
  JS 只操作 `hidden` 类和 `disabled` 属性，所以**没动 JS 就生效**。
- **造型记忆点**：左端 34×34 的「拍板」—— 45° 琥珀/墨交替斜条纹（`repeating-linear-gradient`），
  琥珀 `--handle` 与裁剪手柄同色，语义指向"剪辑动作"。悬停时 `rotate(-8deg) scale(1.05)` 像合板。
- **定位**：`right: max(20px, calc((100% - 980px) / 2 + 20px))` —— 跟 `.app` 内容区右边缘对齐，
  窄屏退化贴边 20px。用 `%` 不用 `vw`（后者含滚动条宽度会错位）。
- **避让**：换片键会压住 header 右侧 `.tagline`。用 `body:has(.reel-bar:not(.hidden)) .tagline { opacity: 0 }`
  让它淡出 —— **纯 CSS、零 JS 改动**这个技巧值得复用。
- **入场**：`reelIn` 关键帧，从右上 `translate(18px,-10px) rotate(4deg)` 拍进来，420ms；包在
  `prefers-reduced-motion: no-preference` 里。
- **状态**：默认 / hover / active / focus-visible(2px 橙环) / disabled(0.42) 全覆盖；min-height 44px。

**临时文件**：`public/reel-tab-preview.html` —— 换片键的独立预览页（带显隐、disabled、重播动效三个按钮）。
用户确认样式后应删除。

### 复用要点
- `:has()` 可以替代"JS 加 body class"来做兄弟/祖先区域的联动避让，改动面小很多。
- 本项目设计系统：暖近黑 `#0b0a09` + 单一强调色熔岩橙 `#ff5a24` + 手柄琥珀 `#ffb020`，
  胶片齿孔母题 `.film-rail`，Bebas Neue / IBM Plex Sans / IBM Plex Mono。新增元件必须在这个语言里做。
